VIMAL PETS & TOYS — MOBILE DROPDOWN ONLY

This add-on changes ONLY the mobile menu.
Your existing desktop navbar, desktop mega-dropdowns, search, cart and wishlist are NOT replaced.

1. Copy vimal-mobile-dropdown-only.css into your existing css/ folder.
2. Copy vimal-mobile-dropdown-only.js into your existing js/ folder.
3. In index.html (and later the other pages that use the same navbar), after:
   <link rel="stylesheet" href="css/navbar.css?v=2">
   add:
   <link rel="stylesheet" href="css/vimal-mobile-dropdown-only.css?v=1">
4. Near the bottom, after your existing:
   <script src="js/navbar.js?v=32"></script>
   add:
   <script src="js/vimal-mobile-dropdown-only.js?v=1"></script>
5. Do NOT remove or edit navbar.js or navbar.css.
6. Test mobile. Desktop should remain exactly as before.
