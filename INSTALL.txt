VIMAL PARTNER UPGRADE - HOW TO INSTALL
======================================

1. SUPABASE (do this first)
   Supabase > SQL Editor > paste all of supabase-partner-upgrade.sql > Run.
   (supabase-orders.sql must already be run - it creates vp_is_admin().)
   Then Storage > Policies: delete any OLD policy on the bucket "seller-kyc-docs"
   that lets everyone read or update files. The bucket must show as Private.

2. COPY FILES into your Vimal-Aqua project (replace when asked)
   css/partner-dashboard.css     NEW
   js/partner-dashboard.js       NEW
   seller-dashboard.html         REPLACES old file
   marketplace.html              REPLACES old file
   seller-signup.html            REPLACES old file (only change: upsert true -> false)

3. Commit + push. Vercel deploys.

4. Test with a partner account:
   - Dashboard > My Documents: upload a file -> it shows "Locked", Upload button is gone.
   - Dashboard > Add Products: try "Link from my website" and "Bulk upload (CSV)".
   - Open marketplace.html: product shows "Buy on <shop> ↗" (website products)
     or "Enquire on WhatsApp" (manual products).

LOCKED after submission (partner cannot change): shop name, owner, phone, address,
PAN, Aadhaar, GSTIN, bank details, verification + subscription status, all documents.
EDITABLE by partner: website link, WhatsApp number, shop description, product price/stock/description/link.
To let a partner re-upload a wrong document, an admin deletes that row in the
seller_documents table (and the file in Storage). Partners cannot do this themselves.
