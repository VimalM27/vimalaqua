VIMAL NAVBAR FORCE REPAIR — ADD-ON ONLY

This add-on does NOT replace your existing navbar.js or navbar.css.
It only activates when <nav class="navbar"> is empty/broken.

1. Copy css/vimal-navbar-force.css into your existing css folder.
2. Copy js/vimal-navbar-force.js into your existing js folder.
3. In index.html (and any page where the navbar is empty), add this CSS in <head> AFTER navbar.css:
   <link rel="stylesheet" href="css/vimal-navbar-force.css?v=1">
4. Add this JS immediately BEFORE </body>, AFTER your existing navbar.js:
   <script src="js/vimal-navbar-force.js?v=1"></script>
5. Save, hard refresh with Ctrl+F5.

IMPORTANT:
- Do not delete navbar.js or navbar.css.
- Do not add the script twice.
- If you are testing the Vercel site, commit/push the two files and HTML changes, wait for deployment, then Ctrl+F5.

The repair creates a desktop navbar and a real mobile drawer if the original navbar is empty. Search uses VPW_PRODUCTS when that file is already loaded, otherwise it falls back to category pages/search-results.html.
