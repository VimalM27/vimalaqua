HOW IT WORKS
  * Menu "🔥 Offers" (desktop + mobile) opens offers.html: all live / coming-up / recently ended offers.
  * Home page order: welcome popup -> "Download the app" popup -> offer popup.
  * The offer popup shows the LIVE offer from js/offers-data.js with an "Offer ends in" countdown, the code
    (Copy also stores it so the cart can apply it, like on offers.html), "Shop this offer" and "See all offers".
  * If nothing is live, it announces the next offer if it starts within 45 days ("Offer starts in" countdown).
    Change UPCOMING_DAYS at the top of the popup JS (0 = show only live offers).
    With today's dates: Diwali ended 11 Nov, so until 15 Dec it shows Christmas Joy as "COMING SOON".
  * Several live offers: the one ending first is shown.
  * Frequency: every home-page load (FREQUENCY = "session" or "day" to show less).
  * Test: yourwebsite/index.html?offerPopup=1   (F12 console explains if it is not shown)

KEEP IN SYNC: offers.html and the popup both read js/offers-data.js. The discount numbers there must match the
coupon rows in supabase-coupons.sql, otherwise the page promises something checkout will not give.
