VIMAL27 SEO – PHASE 2 ADD-ON

FILES INCLUDED
==============
1. product.html
2. js/seo-product.js
3. sitemap.xml

WHAT THIS UPDATE DOES
=====================
PRODUCT SEO
- Dynamically updates the browser title for each product.
- Creates a product-specific meta description from the product data.
- Updates the canonical URL for product pages.
- Adds Schema.org Product structured data.
- Adds price/availability to structured data only when those values exist.

SITEMAP
- Removes common private and transactional pages from the sitemap.
- Keeps 118 public URLs for search engines.

HOW TO INSTALL
==============
If you use Git/GitHub:
1. Back up your current project.
2. Copy these files into the matching locations:
   product.html
   js/seo-product.js
   sitemap.xml
3. Commit and deploy.
4. After deployment, submit https://vimal27.in/sitemap.xml in Google Search Console.

IMPORTANT
=========
- Do not add admin, login, cart, checkout, order or account pages to the sitemap.
- Product structured data is strongest when each product has a real description,
  image, price and availability.
- Do not invent ratings, reviews, stock or prices for SEO.
