VIMAL27 LOGO CURSOR UPDATE

HOW TO INSTALL
1. Make a backup of your existing website folder.
2. Extract this ZIP into the ROOT of your existing Vimal-Aqua project folder.
3. Allow the files to overwrite the existing files.
4. Upload/deploy the updated website files to your hosting.
5. Open the site on a desktop/laptop and press Ctrl+F5.

The shared CSS and JavaScript enable the logo cursor on all 142 root-level HTML pages.
Five pages that were missing the shared enhancement references have been updated.
The cursor uses images/vimallogo.png. Mobile/touch devices keep normal touch interaction.

This ZIP is a patch, not a complete website backup. Extract it over your existing project; do not replace the entire project with this ZIP.
