VIMAL27 WEBSITE ADD-ON UPGRADE
==============================

This folder is an enhanced copy of the original Vimal-Aqua project.
The original uploaded project was not overwritten or deleted.

NEW ADD-ON FILES
-----------------
css/vimal27-enhancements.css
js/vimal27-enhancements.js

WHAT THE ADD-ON IMPROVES
-------------------------
- Keeps the existing Vimal Pets & Toys pages and functionality.
- Adds a responsive consistency layer for desktop/tablet/mobile.
- Improves mobile navigation/menu presentation without removing the existing menu content.
- Prevents common horizontal overflow on account, cart, wishlist, product and dashboard pages.
- Improves product-detail responsiveness.
- Adds mobile-friendly wishlist/cart/dashboard layout safeguards.
- Adds breadcrumbs to inner pages.
- Adds quick-shopping links on the existing homepage.
- Adds WhatsApp support shortcut.
- Adds back-to-top button.
- Adds search suggestions for the site's main categories.
- Adds basic accessibility improvements and keyboard Escape support.
- Adds lazy loading/async decoding to images where safe.
- Keeps existing colors, logo, hero, product data, Supabase and payment code intact.

SECURITY NOTE
-------------
The source project contains Android signing material under android-app/.
Do not publish a release keystore or its base64 representation to a public
repository. Rotate/revoke it if it has ever been exposed publicly.

The enhancement layer does not contain Razorpay secret keys or Supabase
service-role keys.

HOW TO USE
----------
Use this Vimal-Aqua-Enhanced folder as the improved website project.
Your original Vimal-Aqua project remains separately available from the
uploaded ZIP.
